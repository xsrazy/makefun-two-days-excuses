One line from an AI agent explaining a missed deadline, built for make.fun's "Two Days of Excuses" bounty.

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
